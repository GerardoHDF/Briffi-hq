# briffi-hq

Centro de operaciones de **Briffi**: marca, estrategia, contenido y motion. Lo usa un equipo de agentes (Claude, ChatGPT, Codex) dirigido por Gerardo.

**Empieza aquí:** `LEEME-PRIMERO.md` → `AGENTS.md` → tu rol en `agentes/`.

| Carpeta | Qué hay |
|---|---|
| `marca/` | Identidad, voz y archivos (logos, personajes) |
| `estrategia/` | Plan de lanzamiento de 90 días, posicionamiento |
| `agentes/` | Los roles del equipo, con su mensaje de arranque |
| `operacion/` | Estado, calendario, decisiones, métricas, ritual semanal, cómo configurar cada herramienta |
| `plantillas/` | Formatos de entrega (foco, guion, carrusel, brief de motion, reporte) |
| `entregables/` | El trabajo de cada semana: `AAAA-S##/rol/` |
| `motion/` | Animaciones con código (Remotion) |

El código de la app vive en otro repo (`GerardoHDF/Boclik`).
