# Cómo configurar cada herramienta (una sola vez)

## Claude (claude.ai) — Proyectos
Crea 2 Proyectos y, en cada uno, sube como **conocimiento del proyecto**: `LEEME-PRIMERO.md`, `marca/voz.md`, `marca/identidad.md`, `estrategia/lanzamiento-90-dias.md`.
1. **"Briffi · Estratega"** — instrucciones: pega el contenido de `agentes/01-estratega.md` y `agentes/07-analista.md`.
2. **"Briffi · Contenido"** — instrucciones: pega `agentes/02-planificador-redes.md` y `agentes/03-guionista-viral.md`. Activa las skills de ganchos y carruseles.
Cuando cambie algo importante en el repo, vuelve a subir el archivo actualizado.

## Claude Code (este tipo de sesión)
Ábrelo sobre el repo `briffi-hq`: lee `CLAUDE.md` → `AGENTS.md` solo. Sirve para Motion (Remotion), para ordenar entregables y para actualizar `estado.md`, `calendario.md` y `metricas.md` directo en el repo. Sobre el repo `Boclik` sirve para Growth/web y producto.

## ChatGPT — Proyecto
Crea el Proyecto **"Briffi · Diseño"**, sube `LEEME-PRIMERO.md` y `marca/identidad.md`, y pega `agentes/05-diseno-piezas.md` como instrucciones. Úsalo para imágenes de apoyo y variaciones. Como respaldo de cualquier rol si se te acaban los créditos en Claude: adjunta el archivo del rol y listo.

## Codex
Conéctalo al repo `briffi-hq` en GitHub. Lee `AGENTS.md` solo. Úsalo para:
- Composiciones de Remotion en `motion/` (cada una en una rama; tú revisas el render).
- Tareas mecánicas: ordenar `entregables/`, pasar guiones al formato de plantilla, actualizar tablas.

## Adobe / Canva
- Canva: crea un **Brand Kit** con colores, Geist y logos de `marca/assets/`, y 3 plantillas fijas: carrusel 4:5, portada de reel, historia.
- Premiere/After Effects o CapCut: una plantilla de proyecto con subtítulos en Geist, zona segura marcada y cierre con logo.

## Para ahorrar créditos
- Tareas largas de texto (lotes de guiones) → el Proyecto de Claude con el rol fijo.
- Tareas mecánicas y de código → Codex.
- Imágenes → ChatGPT.
- No le pidas a un rol lo que es de otro: cada chat corto y enfocado gasta menos y sale mejor.
