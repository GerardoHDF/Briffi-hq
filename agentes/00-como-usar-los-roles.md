## Cómo se usa
1. Abre un chat dentro del Proyecto del área.
2. Escribe la skill y el rol con la tarea: `/briffi-contenido como guionista, escribe 3 guiones del pilar "El oficio sin filtro"`.
3. El chat ya sabe quién es, cómo habla Briffi, qué se puede prometer y cómo entregar.
4. Guardas la entrega en el repo (o se la pides a Claude Code / Codex) y pasas la tarea a **Para revisar** en Notion.

Cada archivo de esta carpeta es el detalle de un rol. Las skills los resumen; el repo manda si hay diferencia.
