**Gerardo es el director:** aprueba lo que se publica, decide prioridades y desempata.

## Cómo arrancar un chat con un rol
1. Abre el chat o el Proyecto de esa herramienta.
2. Pega el bloque **"Mensaje de arranque"** que trae cada rol.
3. Si la herramienta no lee el repo (ChatGPT, Claude.ai), adjunta `LEEME-PRIMERO.md`, `marca/voz.md` y el archivo del rol. Mejor aún: déjalos fijos en el Proyecto (ver `operacion/herramientas.md`).
4. Al terminar, pide: "Dame el texto para actualizar estado.md y decisiones.md". Pégalo en el repo (o que lo haga Codex/Claude Code).
